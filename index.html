Habilidades

Com conhecimentos em HTML5, CSS3 e JavaScript, consigo dar vida a ideias de forma visual e funcional. No CSS3, desenvolvi habilidades para criar designs responsivos usando grid e flexbox para layouts responsivos, garantindo que as interfaces se adaptem perfeitamente a diferentes dispositivos.Aplico transições e animações para deixar as interações mais dinâmicas, e utilizo técnicas para melhorar a estética e a funcionalidade das interfaces. Utilizando JavaScript, tenho experiência em melhorar a dinâmica e o desempenho das aplicações web, consigo implementar funcionalidades que aprimorem a interatividade e tornam a experiência do usuário mais eficiente e fluida. Além disso, utilizo ferramentas de controle de versão, como Git e GitHub, para gerenciar o código-fonte, mantendo um histórico de alterações completo e bem documentado.
